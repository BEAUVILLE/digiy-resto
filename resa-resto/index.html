MODÈLE SARLAT

Réserver une table.

Choisissez simplement le jour, l’heure, le nombre de personnes et la zone souhaitée. Si une table réelle est disponible, la réservation est confirmée immédiatement.

Règle de réservation
Votre table est conservée 15 minutes après l’heure réservée. Passé ce délai, elle peut être réattribuée. Pour un premier service, la libération avant le service suivant ne s’applique que si cette table est réellement réservée ensuite.

RESA est accessible 24/24, mais seules les heures déclarées par le restaurant peuvent être réservées.
